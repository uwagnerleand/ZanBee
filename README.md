# ZanBee — Catálogo de Vendas

Catálogo digital interativo desenvolvido em React + Vite + TailwindCSS para a loja **ZanBee** (Óbidos, Pará).

## 🚀 Tecnologias Utilizadas
- **React** (v19) com **TypeScript**
- **Vite** (para build ultra-rápido)
- **TailwindCSS** (estilização rápida e moderna)
- **Express / Node.js** (para servir a aplicação)

## 📁 Principais Recursos
- Vitrine de produtos focada na coleção **Universo Encantado**
- Filtro e busca de produtos em tempo real
- Carrinho de pedidos interativo com envio direto para o **WhatsApp**
- Exibição de formas de pagamento integradas (Pix, Cartão, Espécie)
- Design totalmente responsivo adaptado para celulares e desktops

## 📦 Como Executar o Projeto

1. Instale as dependências:
   ```bash
   pnpm install
   ```
2. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Gere o build de produção:
   ```bash
   npm run build
   ```
